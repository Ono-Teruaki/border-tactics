# Border Tactics 設計メモ（v0.4）

- UIは白基調・チェス盤風の3D（three.js）。ピンチ・ホイール・ボタンでズームでき、ズーム中はドラッグで移動できる
- v0.1 のルールは `git tag v0.1` に残しています

数値はすべて `src/engine/rules.ts` にあります。ここにはルールの考え方と、決まっていないことを書きます。

## コンセプト
- 1対1、4人部隊、同時ターン制で戦う
- 武器のカスタマイズはなし。**編成と動かし方**だけで戦略を作る
- 柱は **情報戦**（見える／見えない、位置の露見）と **地形**

## 1ターンの流れ（v0.3）
1. 両軍が全ユニットに **移動先** と **狙う敵（任意）** を決める。狙えるのは今見えている敵だけ
2. **移動**: 全員が同時に動く。経路を問わない瞬間移動扱い
   - 同じマスに複数が入ろうとした場合は、移動してきた側が全員元の位置へ弾かれる（連鎖も解決する）
   - 静止しているユニットのマスに入ろうとした場合は、入ろうとした側が弾かれる
   - 入れ替わりは許可
   - 敵同士で弾かれた場合は、互いの位置が露見する
3. **交戦**: 狙いのあるユニットが「速」の高い順に1体ずつ撃つ（同じ速なら乱数で決める）。撃つ前にベイルアウトしたユニットは撃てない（相打ちを減らす）
   - 撃てる条件: 狙った敵が移動後も味方に見えている、射程内、射線が通る、張り付き遮蔽でない、スナイパーは移動1マス以内
   - 弾数ぶん命中判定。命中率 = 基本命中 − 距離減衰×(距離−1) − 遮蔽 ± 高低差（5〜99%）
   - ダメージ（1発） = 攻² ÷ (攻 + 守) × (1 ± 15%)
4. 撃ったユニットは位置が露見する。HPが0になったら即ベイルアウト

## 隠れ具合（撃ち手から見た対象。`rules.combat`）
- 遮蔽:半（−25%）: 撃ち手の方向（主方向）に隣接するマスがビル
- 遮蔽:小（−12%）: 斜め側（副方向）に隣接するマスがビル
- 屋上から地上へ撃つと +10%、地上から屋上へ撃つと −10%
- 近接（距離1）は遮蔽なし

## 演出
- 実行後、カメラが「味方の移動 → 見えた敵の移動 → 交戦（速の順）→ ベイルアウト」の順に1つずつ寄って映す
- 字幕で「誰が誰を・命中率・遮蔽・何発当たったか」を表示する。速度は ×1 / ×2 / ×3 で切り替えられ、スキップもできる

## 遮蔽（`rules.cover`）
- **射線上にビルがあれば撃てない**。屋上からでも同じ。ただし屋上からビル越しに「見る」ことはできる（索敵の役割）
- **張り付き**: 屋上から撃つとき、撃ち手の方向に面したビルに張り付いている地上の敵は撃てない（真下を狙えない）。地上から撃つ場合は関係ない

## フィールド
- 正方形。出撃位置は対角の角の 2×2（自軍が左下、敵が右上）
- ビル位置は点対称
- サイズは 7 / 9 / 11 の3種類（まだ検討中）

## 視界・地形
- 視界は全員で共有する。視界の距離はマンハッタン距離で測り、視線が通るかも判定する
- 見えていない敵は「最後に見た位置」と「何手前か」を表示する
- 出撃位置と敵の編成は、お互い最初から分かっている

| 地形 | 移動 | 視線 | 特殊 |
|---|---|---|---|
| 地上 | 1 | 通る | — |
| ビル | 2（登る） | 地上同士の視線を遮る | 屋上にいると視界+2・射程+1。ビル越しに見通せるが、撃つことはできない |

## 勝敗（未確定）
- 既定: 12ターン終了時点の撃破コスト合計で判定。全滅したら即終了
- 候補: 全滅のみ／撃破数／撃破コスト。シミュレーションでは3つ全部を並べて出す

## シミュレーション
- `npm test`: 同時解決ルールの仕様テスト
- `node sim/replay.ts record.json`: 終了画面の「棋譜をコピー」で得たJSONを再生
- `npm run sim [-- --games N --quick --variant sim/variants/x.json]`
  - 結果は `sim/results/<名前>.md` と `.json` に出る
  - variant にはルールの差分（`rules.ts` と同じ形）と、任意で `"maps": ["city"]` を書ける
- CPUは自軍から見える情報（Observation）だけで判断する。真の盤面は見ない
- 「クリア可能性」は、プレイヤー代理AI（cpu／aggressive／cautious）が CPU に勝つ率で見る。人間はこれより上手い前提で目安にする

## 未決事項・論点
- 勝利条件
- 移動を経路ありにするか（すれ違い禁止・待ち伏せの成立）
- 索敵の価値: 射手の視界が射程以上あると、索敵が射撃に効かない（`sim/variants/scout-matters.json` を参照）
- スナイパーが屋上と組むと強すぎる（v0.2 の編成総当たりで SSSS が1位）
- フィールドサイズ
- 敵の出撃位置を既知にするか
- ターン上限
- 陣地バイアス: CPU同士の同編成で、右上側(side1)の勝率が v0.2 でも全マップで高い。AIの決定順に原因があるのか、エンジンに原因があるのかを要調査
