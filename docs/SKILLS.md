## メタ分析の履歴（`npm run meta`、126編成の総当たり×3マップ×2回、94,500戦）
結果ファイルは `sim/results/meta-*.md`。

### v0.7
- **防護兵が一強**だった。上限ルール内の上位20編成はすべて防護兵入りで、1位は SSDD（84%）。防護兵が0体だと40%、1体で59%
- 強さの原因は**スキル（カバーリング）**。スキルを外すと、上位はアタッカーとガンナーの混成（AGGR, AGSR, AAGG）に入れ替わる。能力値を下げても（HP26／守14）、1手に庇える数を1発に制限しても、上位は防護兵入りのまま
- 「防護兵＋衛生兵＋G/A」の固めは平均60%で強いが、最強ではない。最強の組み合わせは「防護兵＋スナイパー」（70%）
- 衛生兵は弱い（1体で47%）。回復量を10にしてもほぼ変わらない
- この時点のCPUはマークを活かしていなかったので、スカウトのスキルの強さは判定できなかった

## 検討した別案

### 「攻撃していないターン」の定義
| 案 | 定義 | 判断 |
|---|---|---|
| **A（採用）** | 狙いを指定しなかったターン | 交戦の前に確定するので、防護を交戦中に使える |
| B | 実際に撃たなかったターン（不発も含む） | 交戦が終わるまで確定せず、防護が成立しないので不採用 |

### スカウト
| 案 | 効果 | 判断 |
|---|---|---|
| **観測（マーク）** | 視界内の敵をマーク | 採用 |
| **透視（ソナー）** | 一定距離内は建物越しでも見える | 採用（距離2。案の段階では3） |
| 隠密 | 攻撃していないとき、距離3以上の敵から見えない | 見せ方が難しいので見送り |
| 誤情報 | 敵側に偽の「最後に見た位置」を残す | 対CPUでは効果を感じにくいので見送り |

### ガンナー
| 案 | 効果 | 判断 |
|---|---|---|
| **制圧射撃** | 2発以上当てた敵を制圧 | 採用 |
| 弾幕 | 外れた弾が隣の敵に当たることがある | 見送り |
| 牽制 | 射程内に入った敵に自動で1発 | 支援ターンと噛み合わないので見送り |

### スナイパー
| 案 | 効果 | 判断 |
|---|---|---|
| **狙撃態勢** | 動かなければ命中+15、遮蔽半減 | 採用 |
| 潜伏狙撃 | 距離5以上から撃っても露見しない | 当時すでに最強だったので見送り |
| 貫通 | 張り付き遮蔽を無視 | 見送り（防護兵・遮蔽への対抗手段の候補） |

### 衛生兵・防護兵の細部
- 衛生兵は自分自身を回復しない。撃破された味方は対象外
- 防護兵: 命中判定は元の対象に対して行う（遮蔽などはそのまま）。防護兵が撃破されたら、それ以降の弾は元の対象に当たる。防護兵自身が狙われた場合は通常どおり受ける
- 未決: 回復量を固定値にするか最大HPの割合にするか。複数の衛生兵の回復を重ねるか

### 視界：構造物の奥
| 案 | 内容 | 判断 |
|---|---|---|
| A. 完全遮断 | 屋上からでも、途中にビルがあれば見えない | 屋上の価値が下がるので不採用 |
| **B. 死角方式** | 屋上からはビル越しに見えるが、ビルの裏側に張り付いた地上のマスは見えない | 採用。張り付き遮蔽と同じ理屈で一貫する |
| C. 高さ比例 | 視点とビルの高さから影の長さを計算する | 盤が小さく効果の割に複雑なので不採用 |

### 追加ユニット案
| ユニット | パッシブスキル | 状態 |
|---|---|---|
| **ジャマー**（電子戦） | 周囲2マスの敵の視界−2。範囲内の敵は「味方の索敵で撃つ」が使えない。スカウトの観測の天敵 | 承認済み・**保留** |
| **擲弾兵**（グレネード） | 範囲攻撃（狙ったマス＋上下左右）。山なりの弾道でビル越しにも撃て、遮蔽を無視するが命中率は低い。防護兵・ビル籠もりの天敵 | 承認済み・**保留** |
| デコイ（囮） | 支援ターンに、敵側に偽の自分を1体見せる | 対CPUで効果が出にくいので後回し |
| 工兵（トラップ） | 支援ターンに、今いるマスに地雷を置く。踏んだ敵はダメージを受けて露見する | 未検討 |
| 指揮官 | 周囲8マスの味方の速+5。撃破されると相手に大量のポイント | 勝利条件（大将戦）の議論とセット |
